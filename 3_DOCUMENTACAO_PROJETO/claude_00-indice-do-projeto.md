## Limite honesto (demo x produção)
O app é um demo funcional completo para apresentar/testar. A produção (OCR real, consultas oficiais automáticas, pagamentos processando valores, biometria real) depende do desenvolvimento do back-end (MVP a partir de ~R$ 109k, ver Custos). Modelos jurídicos = revisar com advogado.
