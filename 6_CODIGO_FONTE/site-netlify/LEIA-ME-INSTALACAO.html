VERIMULTA

Instalação no seu servidor

Este pacote é a raiz do site: extraia e está no ar. Sem banco de dados, sem dependências — funciona em qualquer hospedagem.

O que tem no pacote

index.htmlSite de vendas (página inicial do domínio)
app.htmlApp demonstrativo completo → fica em seudominio.com.br/app.html
manifest.json + icones/Fazem o app virar ícone com a marca ao usar "Adicionar à tela inicial" no celular
.htaccessConfiguração Apache/cPanel: HTTPS forçado, cache e compressão
robots.txtLibera indexação no Google

Opção A — cPanel (a mais comum)

1Entre no cPanel da sua hospedagem e abra o Gerenciador de Arquivos.
2Entre na pasta public_html (ou a pasta do domínio/subdomínio desejado).
3Clique em Carregar (Upload) e envie o arquivo Verimulta_Servidor.zip.
4Volte à pasta, clique com o botão direito no ZIP → Extract / Extrair ali mesmo.
5Apague o ZIP após extrair. Acesse seudominio.com.br — o site já está no ar, e o app em /app.html.
6Ative o SSL grátis (Let's Encrypt) em cPanel → SSL/TLS Status → Run AutoSSL. O .htaccess já redireciona tudo para HTTPS.

Opção B — FTP (FileZilla)

1Extraia o ZIP no seu computador.
2Conecte no servidor com os dados de FTP da hospedagem.
3Arraste todo o conteúdo da pasta extraída (inclusive o .htaccess, que é oculto — ative "mostrar arquivos ocultos") para dentro de public_html.

Opção C — VPS / Nginx

1Envie os arquivos para a pasta do site, ex.: /var/www/verimulta.
2O .htaccess não vale no Nginx — aponte o server block com root /var/www/verimulta; e index index.html; e use o Certbot para o HTTPS.

Depois de instalar (3 ajustes)

1Formulário da lista de espera: crie um form grátis em formspree.io, copie o endpoint e cole no TORQON_CONFIG no final do index.html (campo formEndpoint). Sem isso o formulário roda em modo demonstração.
2Links de pagamento: quando criar as cobranças no gateway (Mercado Pago, Stripe ou Asaas), cole os links em paymentLinks no mesmo TORQON_CONFIG.
3Teste no celular: abra /app.html, use "Adicionar à tela inicial" e confira o ícone azul com o check amarelo.
Importante: este pacote contém apenas os arquivos públicos. Os documentos de negócio (PRD, naming, lançamento, deck) ficam no outro ZIP — não os envie ao servidor público. O app é um demonstrativo: OCR real, consultas oficiais automáticas, pagamentos e biometria real entram com o desenvolvimento do MVP (handoff pronto).
